开启手机定位

东钱湖导览会读取你的位置，用于计算到景点的距离、显示蓝色定位点，并在导航时跟随移动。

如果浏览器没有弹出授权

1. 手机浏览器需要 HTTPS 或 localhost；直接双击本地 HTML 时，部分浏览器会禁用定位。
2. 在浏览器地址栏左侧的站点设置里，把“位置”改为“允许”。
3. iPhone 需在 设置 → 隐私与安全性 → 定位服务 → 浏览器 中开启。

本地演示

在项目目录运行 python server.py，用手机访问电脑局域网地址（或 localhost），定位权限更容易触发。

隐私：位置只在你的浏览器内使用，不会上传到服务器；关闭页面或点“停止定位”即可结束。

小东 · DeepSeek 接入

公共网站默认通过站点的 /api/chat 使用管理员配置的 DeepSeek，普通访客无需填写 Key。若站点未配置，小东会自动使用内置讲解库；高级用户也可以填自己的 Key 直连官方接口。

启用 DeepSeek 深度问答关闭时使用本地讲解库
公共站点由服务端环境变量配置；这里填的 Key 只保存在本机浏览器 localStorage。
可直接填官方地址；若网络或跨域拦截，再改用本地代理 /api/chat（Key 放服务端环境变量，浏览器可留空）。
公共站点可直接点这里测试管理员配置的通道；自填 Key 时也可测试。
为什么不能直接嵌入网页版？ chat.deepseek.com 设置了 X-Frame-Options / CSP，禁止被第三方网站 iframe 内嵌。强行嵌入只会得到空白框，所以这里采用“同名助手 + API 接入”的方式。

关于「小东智游」

这是什么

杭州电子科技大学第二届 AIGC 应用创新大赛「AI 辅助开发 · 创意产品原型」参赛作品，公共测试版。选题：东钱湖旅游区可交互导览。

核心功能

① 可缩放电子地图：高德街道/卫星底图，标出 7 处景点、交通线、观光船码头与服务点；点标点即出距离、票价、简介。
② 小东 AI 助手：本地讲解库 + 可选 DeepSeek API，回答历史、名人、路线、服务问题。
③ 到站讲解：选择主题路线后模拟行进，到达景点自动弹出历史与名人讲解。
④ 交通与观光船：地铁 4 号线、环湖公交、湖上观光航线。
⑤ 联网导航与定位：OSRM 在线路线、步行/驾车切换、手机持续定位与跟随。

资料与边界

历史资料参考维基百科「东钱湖」「南宋石刻公园」「忠应庙」「岳鄂王庙」「史浩」等公开条目；票价为参考价，以景区当日公示为准。服务点为原型模拟点位。地图底图 © 高德地图，仅用于课程原型演示。

技术说明

单页 HTML/CSS/JS，无框架依赖；高德栅格瓦片 + 自研轻量地图引擎（投影、瓦片、标点、路线、模拟行进）；DeepSeek 通过官方 Chat Completions API 接入，Key 仅存本地。

使用提醒：首次打开需联网加载地图瓦片；定位需要浏览器授权，若不可用会自动回退到“东钱湖游客中心”作为距离起点。位置只在浏览器本地使用，不上传服务器；对话若走站点的 DeepSeek 通道，会发送给 DeepSeek 用于生成回答，不用于其他用途。
